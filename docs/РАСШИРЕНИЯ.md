# Расширения

Расширение — это внешний инструмент, который Василиса может вызывать во время работы:
доступ к репозиторию задач, база знаний, браузер, внутренний сервис компании. Расширения
работают по открытому протоколу [Model Context Protocol](https://modelcontextprotocol.io/),
поэтому подойдёт любой MCP-сервер, а не только написанный специально для Василисы.

## Встроенные расширения

Часть возможностей встроена в саму сборку и включается переключателем в
**Настройки → Расширения**:

| Расширение | Что даёт |
|---|---|
| Developer | Работа с файлами и запуск команд. Включено по умолчанию — на нём держится основная работа с кодом |
| Computer Controller | Управление компьютером: сбор данных со страниц, кеширование файлов, автоматизация |
| Memory | Запоминает ваши предпочтения между сеансами |
| Auto Visualiser | Сам рисует графики по данным в переписке |
| Analyze | Разбор структуры кода: файлы, символы, граф вызовов. Включено по умолчанию |
| Chat Recall | Поиск по содержимому прошлых переписок |
| Extension Manager | Включает и выключает расширения прямо во время сеанса. Включено по умолчанию |
| Skills | Подхватывает инструкции-навыки из файлов `SKILL.md`. Включено по умолчанию |
| Todo | Ведёт список задач по ходу работы. Включено по умолчанию |

## Подключить свой MCP-сервер

1. **Настройки → Расширения → Добавить расширение**.
2. Выберите тип: команда (`stdio`) или адрес (`HTTP`).
3. Для команды укажите, чем запускается сервер, например `npx -y @modelcontextprotocol/server-github`,
   и переменные окружения, если серверу нужен токен.
4. Сохраните. Расширение появится в списке, его инструменты станут доступны агенту.

Расширение получает те же возможности, что и сам агент: доступ к файлам, сети и командам.
Подключайте только те серверы, которым доверяете, и не выдавайте им лишних токенов.

## Подсказки проекта

Файл `.goosehints` в корне проекта Василиса читает в начале работы. Туда стоит положить то,
что иначе придётся повторять в каждом чате: как запускать тесты, каких каталогов не касаться,
какие соглашения приняты в коде. Настраивается через **Настройки → Чат → Подсказки проекта**.

## Если расширение не запускается

- Проверьте, что команда из настроек работает в терминале сама по себе.
- Посмотрите, не требует ли сервер токена, которого вы не задали.
- В закрытом контуре без доступа в интернет `npx` не сможет скачать пакет — установите
  MCP-сервер заранее и укажите путь к уже установленному исполняемому файлу.
- Логи запуска лежат в каталоге данных приложения, подкаталог `logs`.
