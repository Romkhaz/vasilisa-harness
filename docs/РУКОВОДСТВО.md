# Агент Василиса — руководство пользователя

Василиса — помощник для работы с кодом, который запускается на вашем компьютере. Она
читает и правит файлы в рабочей папке, запускает команды и отвечает по-русски. Модель
работает не на вашей машине: Василиса обращается к сервису инференса по выданным вам
ключу и адресу.

## 1. Установка

### Windows

1. Скачайте `Vasilisa-setup.exe` из артефактов сборки (артефакт
   `Vasilisa-win32-x64-setup`).
2. Запустите его. Установщик не подписан, поэтому SmartScreen покажет окно
   «Система Windows защитила ваш компьютер».
3. Нажмите **Подробнее**, затем **Выполнить в любом случае**.
4. Приложение установится в профиль пользователя и появится в меню «Пуск» как
   «Агент Василиса».

Если установщик запускать нельзя, возьмите архив `Vasilisa-win32-x64.zip`,
распакуйте в любую папку и запустите `Vasilisa.exe` — установка не требуется.

### macOS

1. Скачайте `Vasilisa.dmg` и откройте двойным кликом. Сборка только под Apple Silicon
   (M1 и новее); под Intel приложение не выпускается.
2. В открывшемся окне перетащите значок «Василиса» на папку «Программы» рядом.
3. При первом запуске macOS сообщит, что приложение из неустановленного источника.
4. Откройте **Системные настройки → Конфиденциальность и безопасность**, найдите внизу
   сообщение о заблокированном приложении и нажмите **Открыть всё равно**.
5. Подтвердите запуск в появившемся диалоге.

Альтернатива для шага 4 — снять карантинный атрибут вручную:

```bash
xattr -dr com.apple.quarantine /Applications/Vasilisa.app
```

Рядом с образом лежит архив `Vasilisa.zip` с тем же приложением — он нужен
автообновлению, устанавливать из него не обязательно.

Если macOS пишет, что приложение **повреждено и его следует переместить в Корзину**,
значит у бандла нарушена подпись — это дефект сборки, а не вашей машины. Такое было
в сборках до исправления ad-hoc подписи; возьмите файл из свежего релиза. Временно
помогает та же команда `xattr -dr com.apple.quarantine`.

### Linux

Соберите или скачайте пакет под свой дистрибутив: `.deb`, `.rpm` или `.flatpak`.
Устанавливайте обычным способом, например:

```bash
sudo dpkg -i vasilisa_*_amd64.deb
```

## 2. Первый запуск

При первом запуске Василиса просит подключиться к сервису инференса. Нужны две вещи,
которые выдаёт администратор:

| Поле | Что вводить | Пример |
|---|---|---|
| Ключ доступа | Выданный вам ключ. Хранится локально в защищённом хранилище системы | `sk-…` |
| Адрес сервиса инференса | Базовый адрес сервиса, включая версию API | `https://inference.example.ru/v1` |

После сохранения Василиса проверяет подключение и подтягивает список доступных моделей.
Если список пуст или подключение не удалось — проверьте адрес: он должен отвечать на
`GET {адрес}/models`.

Изменить ключ или адрес позже: **Настройки → Провайдеры**.

## 3. Выбор модели

Модель выбирается в шапке окна чата. Список приходит от сервиса инференса. Если нужной
модели нет в списке, её имя можно ввести вручную — выберите «Указать свою модель» и
впишите идентификатор, который назвал администратор.

## 4. Работа с проектом

1. Откройте папку проекта: **Файл → Открыть папку** (или перетащите папку на окно).
   Василиса работает в границах этой папки.
2. Опишите задачу в чате обычным текстом: «найди, где формируется отчёт, и добавь колонку
   с датой».
3. Василиса покажет, какие файлы читает и какие команды хочет выполнить. В зависимости от
   режима она спросит подтверждение или выполнит действие сама.

### Режимы подтверждения

Режим переключается в настройках чата:

- **Автоматически** — выполняет действия без вопросов;
- **Спрашивать всегда** — подтверждение на каждое действие;
- **Спрашивать об опасном** — подтверждение только для чувствительных операций;
- **Только чат** — отвечает текстом, ничего не выполняет.

Для незнакомого проекта разумно начать со «Спрашивать об опасном».

### Подсказки проекта

Файл `.goosehints` в корне проекта — текстовые заметки, которые Василиса читает в начале
работы: соглашения по коду, как запускать тесты, чего не трогать. Настраивается через
**Настройки → Чат → Подсказки проекта**.

## 5. Полезные мелочи

- **Новый чат** — `Ctrl+N` (macOS: `Cmd+N`). Каждый чат помнит свою историю.
- **Показать окно Василисы** из любого приложения — глобальное сочетание в
  **Настройках → Сочетания клавиш**.
- **История переписок** — раздел «Сеансы»: там же поиск по прошлым разговорам.
- **Язык интерфейса** — **Настройки → Внешний вид → Язык**. По умолчанию русский;
  английский оставлен запасным вариантом.

## 6. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| «Не удалось подключиться к внешнему серверу» | Адрес сервиса инференса и доступность сети до него |
| Список моделей пуст | Отвечает ли `GET {адрес}/models`, верен ли ключ доступа |
| Модель отвечает по-английски | Язык интерфейса должен быть русским: Василиса передаёт его модели как язык ответа |
| «Василиса не смогла запуститься» | Логи запуска в каталоге данных приложения, подраздел `logs/startup` |

Каталоги данных:

- Windows — `%APPDATA%\Vasilisa\vasilisa\`
- macOS — `~/Library/Application Support/Vasilisa/vasilisa/`
- Linux — `~/.config/vasilisa/`

Настройки хранятся в `config.yaml` в этом каталоге, ключ доступа — в системном хранилище
секретов под именем службы `vasilisa`.
