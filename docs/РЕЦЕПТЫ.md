# Рецепты

Рецепт — это сохранённая заготовка сеанса: задача, инструкции, набор расширений и
настройки в одном файле. Пригодится, когда одну и ту же работу делают регулярно или когда
удачный сценарий нужно передать коллеге, не пересказывая его шагами.

## Создать из текущего сеанса

1. В открытом чате нажмите кнопку создания рецепта внизу окна.
2. Проверьте поля: название, описание, инструкции агенту, список расширений, параметры,
   которые запрашиваются при запуске.
3. Сохраните в библиотеку рецептов или сразу запустите в новом сеансе.

Создать пустой рецепт можно и из боковой панели: **Рецепты → Создать рецепт**.

## Запустить

Библиотека рецептов открывается из боковой панели. Оттуда рецепт запускается в новом
сеансе; если в нём заданы параметры, Василиса спросит их значения перед началом.

Рецепт можно вызвать и ссылкой вида `vasilisa://recipe?config=...` — такие ссылки
открываются в приложении. Ссылка из чужой рассылки — это чужие инструкции агенту, поэтому
перед запуском посмотрите, что внутри: приложение показывает состав рецепта до начала работы.

## Где лежат

Библиотека рецептов — подкаталог `recipes` в каталоге данных приложения; сами каталоги
по операционным системам перечислены в [руководстве](РУКОВОДСТВО.md#6-если-что-то-не-работает).
Рядом работает второй источник: каталог `.goose/recipes` внутри самого проекта — такие
рецепты видны только когда вы работаете в этом проекте.

Это обычные файлы YAML, поэтому рецепт удобно хранить в репозитории рядом с кодом и
обновлять вместе с ним.

## Из чего состоит рецепт

| Поле | Назначение |
|---|---|
| `title`, `description` | Название и краткое описание — по ним рецепт видно в библиотеке |
| `instructions` | Постоянные инструкции агенту на весь сеанс |
| `prompt` | Первое сообщение, с которого начинается работа |
| `extensions` | Какие расширения включить |
| `parameters` | Значения, которые запрашиваются при запуске и подставляются в текст |
| `sub_recipes` | Вложенные рецепты для отдельных подзадач |

Обязательны `title`, `description` и хотя бы одно из `instructions` или `prompt`.
